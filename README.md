# 📄 currículo

Currículo pessoal desenvolvido em **HTML puro**, com informações de formação acadêmica, experiência profissional e objetivo de carreira.

---

## 📋 Sobre o Projeto

Este repositório contém o código-fonte de um currículo web criado com HTML5. O projeto demonstra o uso de HTML para estruturar informações pessoais e profissionais de forma organizada.

---

## 🛠️ Tecnologias Utilizadas

- ![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white) **HTML5** — estrutura e marcação do conteúdo

---

## 📂 Estrutura do Projeto

```
curriculo/
├── index.html       # Currículo principal
└── README.md        # Documentação do projeto
```

---

## 📝 Conteúdo do Currículo

- **Dados Pessoais** — nome, nacionalidade, estado civil, contato
- **Objetivo** — área de interesse profissional
- **Formação Acadêmica** — ensino médio completo, cursando ensino superior
- **Cursos Complementares** — Designer Interface Web
- **Experiência Profissional** — experiências anteriores

---

## 🚀 Como Visualizar

1. Clone o repositório:
   ```bash
   git clone https://github.com/MIcodebot/curriculo.git
   ```
2. Abra o arquivo `index.html` no seu navegador.

## 📚 Conceitos Praticados

- Estrutura semântica HTML (`<header>`, `<section>`, `<article>`)
- Listas de informações (`<ul>`, `<li>`)
- Formatação de texto (`<h1>` a `<h3>`, `<p>`, `<strong>`)
- Organização de conteúdo em seções
